# 整理课后资源(After-class)

> 大量输入是语感和听力的来源:泛听保量、精听保质、阅读提表达,摘出的表达进词库做间隔重复;语法作业单独成文件,小测验留给下节课口答。

## 输入

用户粘贴的老师课后推荐,三种类型可单独或混合出现:

- **视频**:YouTube 链接,通常标注**精听**或**泛听**
- **阅读**:文章、材料或其他练习
- **语法作业**:语法点讲解(公式、例句)+ 小测验,下节课课堂口答

目标课文件夹默认为最近一次课的 `lessons/YYYY-MM-DD/`(不确定时询问)。

## 输出 1:lessons/YYYY-MM-DD/after-class.md

```markdown
# 课后任务 · YYYY-MM-DD

> 完成一项勾一项;精听摘到的表达同步到本课 vocab.md

## 精听(每条:盲听 2 遍抓大意 → 逐句跟读模仿 → 摘 3 个表达)

- [ ] **<视频标题>** <URL>
  - 摘到的表达:(完成后填写,同步 vocab.md,来源=精听)

## 泛听(磨耳朵:通勤/运动时听,听不懂的点记下来不查词典)

- [ ] **<视频标题>** <URL>

## 阅读(读 2 遍:第一遍抓大意,第二遍摘表达和语法)

- [ ] **<材料标题/来源>** <链接或说明>
  - 学到的表达/语法:(完成后填写,同步 vocab.md,来源=阅读)

## 口语自测(可选)

- 不看文稿,用 3–5 句英语复述本周 material 的核心内容(录音自查)
```

规则:

- 视频必须保留完整 URL;标题从链接或用户提供的信息取,取不到就先占位
- 已有 after-class.md 时**追加**新条目,不覆盖已完成的打卡记录
- 精听/泛听分类以老师标注为准;未标注时按内容判断并说明理由

## 输出 2:lessons/YYYY-MM-DD/grammar.md(仅当老师布置语法作业时)

语法作业单独成文件,**不一定每节课都有**;结构如下(canonical 范例:`lessons/2026-09-16/grammar.md`):

```markdown
# 语法巩固 · YYYY-MM-DD

> 来源:老师课后布置 | 状态:[ ] 小测验未完成 / 下节课课堂口答
> 主题:<语法点一句话>

(老师布置的原话,保留作业要求,如「完成小测验,下节课课堂口答」)

## 公式 / 讲解(保留老师原貌)
(公式、生成步骤、示例句,原样归档,只做格式清理)

## ❓ 小测验
(原样保留题目,**留白不填**——要自己写或下节课口答)

---

## 参考答案(先自己完成,再核对)
(若老师没给答案,AI 生成一版放在文末分隔线之后,防止提前看到;
 附 2–3 条自检要点,如语序、三单、时态还原)

## 与专项的关联(可选)
(若该语法点与嵌套从句专项相关——如宾语从句、定语从句——
 用 2–3 句说明它如何服务于「说出带从句的长句」,并给 1 个下次作文的主动使用建议)
```

规则:

- **保留老师讲解原貌**,不重组不简化——语法讲解的教学顺序是老师设计的
- 原材料中的笔误(如陈述语序示例写错)可修正,但必须在文末「注」中说明改了什么
- 小测验**永远留白**;参考答案放分隔线之后的文末,并标注「先自己完成再核对」
- 同一课多次布置语法 → 追加到已有 grammar.md,按作业编号分节

## 输出 3:lessons/YYYY-MM-DD/vocab.md

词汇表格式(**字段顺序固定**,`scripts/build_anki_csv.py` 依赖它):

```markdown
# 词汇 · YYYY-MM-DD

| 英文 | 音标 | 中文 | 例句 | 来源 |
|---|---|---|---|---|
| replication lag | /ˌreplɪˈkeɪʃən læɡ/ | 复制延迟 | The dashboard that monitors replication lag turned red during the backfill. | 材料 |
```

- 来源取值:`材料` / `预习` / `作文` / `精听` / `泛听` / `阅读`
- 例句优先用材料或视频里的原句(可简写),必须是完整句子
- 每课精选 **8–15 条**即可,宁缺毋滥;表达类(词组/句式)同样入表,「英文」列可填短语
- 已有 vocab.md 时追加,去重(同一课内不重复)

## 收尾:更新 dashboard.md

- 该日期行勾选「精听 ✓」「泛听 ✓」「阅读 ✓」「语法 ✓」(语法在小测验完成并口答后勾;只归档未完成时先不勾)
- 若本课词汇条目变化,刷新「累计统计」的词汇数

## 提醒(酌情)

- 词汇积累几课后,可运行 `python3 scripts/build_anki_csv.py` 生成 `vocabulary/anki-export.csv` 导入 Anki 做间隔重复
- 周日晚可说「周回顾」让 AI 汇总本周完成度
