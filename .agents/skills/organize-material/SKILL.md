# 整理课程材料

## 目标

把老师提供的材料**原样归档**到当天的课文件夹,作为整节课其他环节(预习/作文/课后)的输入源。材料是唯一事实来源,后续所有 AI 生成物都基于它。

## 输入

用户粘贴的老师材料(可能是对话脚本、新闻文章、讨论题等任意格式)。

## 步骤

1. **确定课程日期**:
   - 材料内注明日期 → 用该日期
   - 用户口头说明日期 → 用该日期
   - 都没有 → 用今天(上课日)
2. **确定文件名**:目标为 `lessons/YYYY-MM-DD/material.md`
   - 若该文件夹已有 `material.md`(同一天多份材料)→ 用 `material-<主题slug>.md`
   - 若文件夹已存在同名文件且内容不同 → 先向用户确认是覆盖还是另存
3. **归档内容**,遵循:
   - **保留原文**:保留原始标题、场景设定、对话、词汇表、思考题的原貌和顺序
   - 只做必要的格式清理(标题层级、表格对齐),**不改写、不翻译、不增删内容**
   - 在文件顶部加一行元数据(如来源类型、英语等级,若材料中有)
4. **更新看板**:在 `dashboard.md` 的「课程日志」表追加/更新该日期行,勾选「材料 ✓」,主题列填一句话主题
5. **提示下一步**:告诉用户可以接着说「生成预习」

## 禁止

- 不要把材料改写成教学格式或添加模板章节
- 不要合并多份材料为一个文件
- 不要跳过归档直接做其他环节
