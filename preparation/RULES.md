# Preparation 编写规则

> 本文件供 AI 在新增 `preparation/YYYYMMDD.md` 时直接引用。canonical 范例：`preparation/20260709.md`。

---

## 1. 定位与目标

**Preparation 是什么：** 基于当天 `materials/` 中的技术话题，帮学员**课前快速理解概念**，并在**技术英语课**上和老师的对话中有内容可接。

**Preparation 不是什么：**

- 不是 material 的复制粘贴或缩写版
- 不是课后复习（那是 `review/` 的职责）
- 不是逐段翻译 material 原文

**学员核心练习目标：** **嵌套从句**——定语从句、状语从句、非限制性从句叠用，用于技术话题的口头表达。

---

## 2. 文件命名与输入

| 项目 | 规则 |
|---|---|
| 文件名 | `preparation/YYYYMMDD.md`，日期与当天 material 一致 |
| 输入来源 | 读取 `materials/YYYYMMDD_*.md` |
| 重点提取 | Background（含故事、文章技术干点、SLA 补充、replication lag 等）、Technical Key Points、Role and Scenario、对话主题线 |
| 禁止照搬 | Dialogue 正文、Vocabulary 原表、Reading Comprehension 原文 |

---

## 3. 语言难度

| 部分 | 难度 | 说明 |
|---|---|---|
| 用自己的话理解 · 中文 | 清晰口语 | 帮助快速建立概念，可稍技术性 |
| 用自己的话理解 · 英文 | **B2** | 技术话题描述，句子可较长，须有从句 |
| 嵌套从句练习 | **B2** | 层层递进，Layer 4 为完整嵌套句 |
| 课堂对话套路 / 跟读 | **B2** | 每段至少含 1–2 个嵌套从句 |
| 课前速览 / 表格 / 中文对照 | 不限 | 以降低认知负担为主 |

**禁止：** 将 preparation 整体写成 B1 短句版（除非用户明确要求降级）。

---

## 4. 内容原则

### 4.1 必须用自己的话复述

- 概念、案例、结论全部**改写**，不得复制 material 对话原文
- 可保留必要技术术语（SLA、failover、canary deployment 等）
- 案例数据（时间、次数、百分比）可与 material 一致，但表述方式须不同

### 4.2 必须包含嵌套从句练习

每个概念板块须有 **Layer 0 → Layer 4**（至少 Layer 1 → Layer 4）递进：

| Layer | 要求 |
|---|---|
| Layer 0 / 1 | 主句或单层从句 |
| Layer 2 | 加定语从句 (that/which/who/whose/where) 或状语从句 (when/because/although) |
| Layer 3 | 两种从句叠加 |
| Layer 4 | 完整嵌套版 + **中文对照** |

从句类型须覆盖：

- 限定性定语从句：that, which, who, whose, where
- 非限制性定语从句：`, which` / `, who`
- 状语从句：when, before, after, because, although, whereas, while, if, so that
- 从句套从句：定语从句内再嵌 that/when/which

### 4.3 必须中英双语的概念理解

每个概念板块标题：

```markdown
### 用自己的话理解（中英双语）

**中文：**
（用自己的话写，2–4 段）

**English (B2):**
（对应英文复述，不是直译，须有从句）
```

## 6. 各板块细则

### 6.1 课前 3 分钟

- 让学员 **3 分钟内**知道今天聊什么、故事怎么走
- 用故事线串起 material 主线，不展开细节
- 有量化数据时做成表格

### 6.2 关键词表

- 每概念 **5–8 个** B2 技术词汇
- 第三列必须是**带从句的例句**，不能只给单词释义
- 例句展示该词在从句中的用法

### 6.3 课堂对话套路

对齐 material 的场景（面试 / 会议 / 需求评审等），至少 **4 个** 老师追问方向 + **1 个** 学员主动发言表。

每个回答：

- 用 **B2** 词汇
- 至少 **1 个嵌套从句**
- 可加粗关键术语

### 6.4 跟读练习

- 按概念分成 **3–5 段**（Part 1, Part 2, …）
- 每段 **4–6 句**，是一段可一口气读完的连贯表述
- 覆盖：概念理解 → 案例 → 对策 → 权衡（按 material 主线取舍）
- 段落之间逻辑连贯，但**不得复制** material Dialogue 原文

### 6.5 附录

- 列出本课用到的从句类型和引导词
- 给 1 条拆句口诀（先找主句 → 标从句 → 从外往里读）

---

## 7. 禁止事项 checklist

生成前自检：

- [ ] 没有大段复制 material 的 Dialogue 原文
- [ ] 没有「英文原文 + 参考译文」式逐段翻译 material Technical Key Points
- [ ] 每个概念都有「用自己的话理解（中英双语）」
- [ ] 英文概念描述达到 B2，不是 B1 短句堆砌
- [ ] 每个概念至少有 1 组 Layer 1–4 嵌套从句练习
- [ ] 课堂套路、跟读、追问回答都含嵌套从句
- [ ] 文件名日期与 material 一致
- [ ] 文末有「课前最少记」

---

## 8. AI 生成工作流

1. 读取 `materials/YYYYMMDD_*.md`
2. 提取 Technical Key Points 小节 → 映射为「概念 1, 2, 3…」
3. 用中文**自己的话**写概念理解，再写 B2 英文复述（非直译）
4. 为每个概念设计关键词表 + 至少 1 组 Layer 递进练习
5. 根据 Role and Scenario 设计课堂对话套路和老师追问
6. 写 3–5 段跟读（覆盖全文主线，嵌套从句，不抄原文）
7. 按禁止事项 checklist 自检
8. 写入 `preparation/YYYYMMDD.md`

## 10. 用户常见调整指令

| 用户说 | 调整方式 |
|---|---|
| 不要用原文 | 加强改写，删除任何 material 原文引用 |
| 要嵌套从句 | 确保 Layer 练习和套路句均含从句套从句 |
| 概念要中英双语 | 补全「用自己的话理解」双语块 |
| 英语 B2 | 提升词汇与句式复杂度，加 whereas / although / which 等 |
| 太复杂 / 用 B1 | **仅当用户明确要求时**降级；默认保持 B2 + 嵌套从句 |
