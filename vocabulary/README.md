# 词汇库

跨课词汇与表达的沉淀中心。词汇按课存放在 `lessons/日期/vocab.md`(本课精听/泛听/阅读/材料/作文里摘的表达),本目录存放汇总产物。

## 文件

| 文件 | 说明 |
|---|---|
| `mistakes.md` | 错误模式本:作文错误的分类统计和完整日志,刻意练习的靶点 |
| `anki-export.csv` | 由脚本生成,导入 Anki 做间隔重复(不要手改,会被覆盖) |

## 间隔重复(Anki)用法

1. 平时正常上课,词汇自动积累在各课 `vocab.md`
2. 每隔几课(或每周回顾时)运行:
   ```
   python3 scripts/build_anki_csv.py
   ```
3. Anki → 文件 → 导入 → 选 `anki-export.csv` → 勾选「允许 HTML 在字段中」→ 字段映射 Front/Back,Tags 列映射为标签
4. 建议建一个牌组 `English::课程词汇`,每日清空到期卡片

## 没有 Anki 时的替代复习

- 遮盖法:看 `vocab.md` 的「中文」列回忆英文,再反向
- 造句法:每个表达口头造 1 个自己工作场景的句子(比背卡片更接近课堂用途)
